- 접근 정책이 회원 컨테이너 안에서도 적용된다. `WORKSPACE_OTHERS=read` 이면 `<접두어>-dev-container-create` 가 다른 회원의 workspace 를 컨테이너의 `/members/<회원>` 에 읽기 전용(`:ro`)으로 마운트한다(`none` 이면 마운트 없음). `SHARED_DEFAULT=ro`·프로젝트별 readers/writers 는 `/shared` 폴더 ACL 이 컨테이너 안에서도 그대로 적용된다. 기존 컨테이너는 `<접두어>-member-update-all` 로 재생성해야 반영된다. `<접두어>-access status` 가 마운트가 어긋난 컨테이너를 알려 주고, `apply` 는 재생성 안내를 낸다.
