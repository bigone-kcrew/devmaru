How it works — 배포 경로와 명령

Core Skill은 중앙 원본(/opt/@@PFX@@/skills)을 기준으로 회원 환경에 동기화됩니다. @@BRAND@@이 관리하는 Skill만 갱신되고, 같은 이름의 개인 Skill은 덮어쓰지 않습니다. 

@@BRAND@@ Core
   ├─ ~/.claude/skills
   └─ ~/.agents/skills

@@PFX@@-skill-sync 기본 제공 Skill을 현재 기준으로 다시 맞춥니다. 여러 번 실행해도 안전합니다.

@@PFX@@-skill install <name> Catalog Skill을 설치합니다. @@PFX@@-skill이 관리하는 대상은 Catalog뿐입니다.

Claude Code에서 /skills를 실행하면 Core Skill과 Plugin Skill이 함께 보입니다. 자세한 순서는 Portal 안내를 참고하세요.

@@BRAND@@ Skills Hub · 기본 제공 Core Skill, Superpowers 워크플로 Skill, 선택 설치용 Catalog Skill을 안내합니다.
