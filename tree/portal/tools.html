Tools Hub

@@BRAND@@이 중앙에서 운영하며 회원이 지금 사용할 수 있는 문서 처리 · 법률정보 · 데이터 검색 도구와 서비스의 카탈로그입니다.

Tool은 실제 실행 기능을 제공합니다. AI가 그 기능을 올바르게 사용하는 방법이 필요하면 Skills Hub를 확인하세요.

@@BRAND@@ Tool 세 계층 · 사용 방법
1. 관리형 MCP — 이미 등록되어 있음

@@BRAND@@이 회원 Claude·Codex에 등록해 둔 계층입니다. 하려는 일을 그대로 요청하면 Agent가 필요한 Tool을 사용합니다. MCP 서버를 직접 실행하거나 설정할 필요가 없고, token이나 header를 입력할 일도 없습니다. Kordoc · MarkItDown · Crawl4AI · Korean Law가 여기에 해당합니다 — 문서는 Kordoc, 그 밖의 일반 파일을 Markdown으로 읽는 것은 MarkItDown, 웹 페이지를 읽어 오는 것은 Crawl4AI, 법령 · 판례는 Korean Law입니다. 로그인 · 클릭처럼 웹을 조작하는 일은 MCP가 아니라 agent-browser Skill이 맡습니다.

Antigravity(agy)는 관리형 MCP 등록 대상이 아닙니다. 같은 개발환경에서 함께 쓰는 별도 Agent이며, 위 Tool은 Claude·Codex에서 바로 쓰입니다. Paseo 앱에서 Antigravity를 쓰기 위한 인증은 Portal의 Agent 인증 안내에 있습니다.

2. 중앙 서비스 — 직접 쓰거나 호출할 때

MCP 뒤에 있는 원본 서비스입니다. 한글 · HWPX · 공문서를 다루는 Kordoc이 여기에 해당합니다. 문서 작업은 Agent에게 그대로 요청하면 되고, API를 직접 호출할 때만 아래 카드의 API 문서와 OpenAPI 명세를 참고합니다.

Crawl4AI도 중앙 Crawl API가 원본입니다. 주소를 아는 페이지 수집과 같은 사이트 내부 링크 순회를 함께 제공합니다. Agent에게 요청하면 얇은 MCP를 거쳐 이 API를 쓰고, 스크립트나 정기 수집기는 개발환경 안에서 같은 API를 직접 호출합니다. 원본 엔진을 직접 다루지는 않습니다.

n8n은 회원마다 자기 계정으로 브라우저에서 직접 쓰는 자동화 서비스입니다. AI와 연동할 API Key는 회원이 Settings → n8n API에서 직접 만들며, 관리자가 공용 키를 나눠 주지 않습니다. 만든 키는 본인 전용입니다.

3. 후보 · 보류 — 아직 제공하지 않음

도입을 검토 중이라 지금은 쓸 수 없는 항목입니다. 아래 목록에서 hold 배지와 점선 테두리로 구분되며, 장애가 아닙니다.

API Catalog — 쓸 만한 공개 API 찾기

한국에서 사용할 수 있는 공개 API를 @@BRAND@@이 중앙에서 모아 둔 목록입니다. 현재 302건을 37개 분류로 정리해 두었고, 개발환경에서 바로 검색할 수 있습니다. Agent에게 «지도 관련 공개 API 찾아줘»처럼 말해도 됩니다.

api-catalog-search <검색어>

목록을 비교하고 어떤 것을 쓸지까지 정리하려면 api-finder Skill을 설치합니다. 목록 자체는 관리자가 주기적으로 갱신합니다.

@@PFX@@-mcp-sync — 관리형 MCP 동기화

Agent에서 등록이 빠져 보이면 관리형 MCP 등록을 현재 기준으로 다시 맞춥니다. 여러 번 실행해도 안전합니다.

@@PFX@@-mcp-sync

여기는 공용 Tool · REST · MCP 기능을 모아 둔 registry입니다. 요청을 대신 처리하는 게이트웨이가 아닙니다. Skill 사용법은 Portal의 Skills & Tools 안내에 정리되어 있습니다.
